# توثيق الأعمال والاختبار — إدارة الترجمات حسب التطبيق

## الهدف من الميزة

تسمح الميزة بعرض نص عام موحّد لكل التطبيقات مع إمكانية تخصيص النص نفسه لعميل محدد، من دون نسخ قاموس الترجمة كاملًا لكل عميل.

- الترجمة الافتراضية: سجل مفتاحه ولغته محددان و`app_id = NULL`، وتظهر لكل التطبيقات.
- ترجمة التطبيق: سجل بالمفتاح واللغة نفسيهما مع `app_id` لتطبيق محدد، وله الأولوية داخل هذا التطبيق فقط.
- الرجوع التلقائي: إذا لم توجد ترجمة خاصة للتطبيق، يعيد الخادم النص الافتراضي.
- اللغات المدعومة حاليًا: العربية `ar-EG` والإنجليزية `en-US`.

## اسم القائمة والغرض منها

| المسار العربي | من يراها | الغرض |
|---|---|---|
| الإعدادات ← إدارة الترجمات | المدير الشامل `SUPER_ADMIN` فقط | تعديل النص الافتراضي أو إنشاء تخصيص لتطبيق محدد والعودة إلى الافتراضي |

لا يرى مدير التطبيق العادي `ADMIN` تبويب «إدارة الترجمات»، ولا تسمح له واجهات الخادم بقراءته أو تعديله.

## حقول الشاشة

| الاسم العربي | الوصف |
|---|---|
| اللغة | اختيار العربية أو الإنجليزية المراد تعديلها |
| نطاق الترجمة | «الترجمة الافتراضية لكل التطبيقات» أو اسم تطبيق محدد |
| بحث | البحث بجزء من مفتاح الترجمة أو النص الفعلي |
| مفتاح جديد | اسم تقني ثابت مثل `menu.example` |
| نص الترجمة | النص الذي سيظهر للمستخدم |
| مخصصة | علامة تعني وجود Override للتطبيق المختار |
| الافتراضي | يعرض النص العام عند العمل داخل نطاق تطبيق |
| حفظ | يحفظ النص في النطاق المختار |
| العودة للافتراضي | يحذف Override التطبيق فقط ويعيد إظهار النص العام |

## تدفقات الأعمال

### تعديل النص الافتراضي

1. يفتح المدير الشامل «الإعدادات ← إدارة الترجمات».
2. يختار اللغة.
3. يختار «الترجمة الافتراضية لكل التطبيقات».
4. يبحث عن المفتاح، يعدّل النص، ثم يضغط «حفظ».
5. تستخدم التطبيقات التي لا تملك Override النص الجديد. التطبيقات التي تملك Override تحتفظ بنصها الخاص.

### تخصيص نص لتطبيق

1. يختار المدير اللغة والتطبيق.
2. تعرض الشاشة النص الافتراضي بجوار المفتاح.
3. يعدّل النص ويضغط «حفظ».
4. ينشئ النظام سجلًا للمفتاح واللغة والتطبيق، ويظهر وسم «مخصصة».
5. يظهر النص الجديد لمستخدمي هذا التطبيق فقط.

### العودة إلى النص الافتراضي

1. يختار المدير اللغة والتطبيق.
2. يضغط «العودة للافتراضي» على مفتاح مخصص.
3. يحذف النظام سجل التطبيق فقط، ولا يحذف النص العام.
4. يصبح النص الفعلي هو النص الافتراضي فورًا.

### إضافة مفتاح جديد

يمكن إضافة مفتاح ونص من أعلى الشاشة. إذا أُضيف في النطاق الافتراضي يصبح متاحًا لكل التطبيقات. وإذا أُضيف داخل تطبيق من دون سجل افتراضي فلن يظهر إلا لذلك التطبيق حتى يُنشأ النص الافتراضي.

## قواعد الأولوية والأمان

```text
الطلب موثّق وله app_id + يوجد Override → ترجمة التطبيق
الطلب موثّق ولا يوجد Override       → الترجمة الافتراضية
الطلب قبل تسجيل الدخول               → الترجمة الافتراضية
لا يوجد أي سجل للمفتاح                → المفتاح/النص الاحتياطي الحالي
```

- يستخرج الخادم `app_id` من JWT، ولا يقبل من واجهة القراءة تحديد تطبيق آخر.
- حزم الترجمة لا تُخزّن عبر وسيط مشترك، وتُرسل مع `Cache-Control: no-store` و`Vary: Authorization`.
- تخزن الواجهة الحزمة باستخدام `(app_id, locale)` لمنع تسرب نص عميل إلى عميل آخر.
- تسجَّل عمليات الحفظ والحذف في سجل التدقيق باسم المستخدم والمفتاح واللغة والنطاق.
- قاعدة البيانات تمنع تكرار `(app_id, translation_key, locale)`، وتمنع PostgreSQL تكرار السجل الافتراضي ذي التطبيق الفارغ.

## خطة اختبار QA لكل التدفقات

### بيانات الاختبار المقترحة

- تطبيقان: `DEMO` و`CLIENT_B`.
- مستخدم `SUPER_ADMIN`، ومستخدم `ADMIN`، ومستخدم عادي.
- مفتاح موجود في اللغتين مثل `nav.settings`.
- نص عربي افتراضي معلوم ونص إنجليزي افتراضي معلوم.

| رقم | الحالة | خطوات الاختبار المختصرة | النتيجة المتوقعة |
|---:|---|---|---|
| 1 | قراءة قبل الدخول | افتح شاشة الدخول بالعربية ثم الإنجليزية | تظهر النصوص الافتراضية فقط ولا يظهر تخصيص أي عميل |
| 2 | رجوع افتراضي | سجّل في `DEMO` لمفتاح بلا Override | يظهر النص الافتراضي |
| 3 | أولوية التطبيق | أنشئ Override عربيًا لـ`DEMO` ثم ادخل إليه | يظهر النص المخصص |
| 4 | عزل العملاء | بعد الحالة 3 ادخل إلى `CLIENT_B` | يظهر الافتراضي ولا يظهر نص `DEMO` |
| 5 | عزل اللغات | خصص العربية فقط ثم اختر الإنجليزية | الإنجليزية تبقى افتراضية |
| 6 | تعديل الافتراضي | عدّل الافتراضي لمفتاح لا يملك Override | يظهر النص الجديد في التطبيقين |
| 7 | بقاء Override | عدّل الافتراضي لمفتاح مخصص في `DEMO` | `DEMO` يحتفظ بالمخصص و`CLIENT_B` يرى الافتراضي الجديد |
| 8 | العودة للافتراضي | اضغط «العودة للافتراضي» في `DEMO` | تختفي علامة «مخصصة» ويظهر النص العام فورًا |
| 9 | إضافة مفتاح عام | أضف مفتاحًا في النطاق الافتراضي | يظهر في حزم التطبيقين |
| 10 | إضافة مفتاح لتطبيق فقط | أضف مفتاحًا داخل `DEMO` | يظهر في `DEMO` ولا يظهر في `CLIENT_B` |
| 11 | البحث بالمفتاح | اكتب جزءًا من المفتاح | تظهر الصفوف المطابقة فقط |
| 12 | البحث بالنص | اكتب جزءًا من النص الفعلي | تظهر الصفوف المطابقة فقط |
| 13 | نص فارغ | حاول حفظ نص فارغ | يمنع الحفظ وتظهر رسالة «نص الترجمة مطلوب» |
| 14 | مفتاح فارغ/طويل | أضف مفتاحًا فارغًا أو أكثر من 150 حرفًا | يمنع الحفظ برسالة عربية مفهومة |
| 15 | تطبيق غير موجود | استدعِ API بمعرّف تطبيق محذوف | `404` مع `I18N_APP_NOT_FOUND` |
| 16 | صلاحية Super Admin | افتح التبويب بحساب `SUPER_ADMIN` | يظهر التبويب وتنجح القراءة والحفظ |
| 17 | صلاحية Admin | افتح الإعدادات بحساب `ADMIN` واستدعِ API مباشرة | لا يظهر التبويب ويرد الخادم `403` |
| 18 | مستخدم عادي | استدعِ API الإدارة مباشرة | يرد الخادم `403` |
| 19 | سجل التدقيق | احفظ Override ثم احذفه | يظهر حدثا `TRANSLATION_UPSERT` و`TRANSLATION_OVERRIDE_DELETE` |
| 20 | انتهاء الجلسة | احفظ بعد انتهاء JWT | يرفض الطلب ويحوّل مسار الجلسة المعتاد إلى الدخول |
| 21 | تحديث فوري | عدّل نص التطبيق المستخدم حاليًا | تتحدث نصوص الواجهة الحالية دون إعادة تسجيل الدخول |
| 22 | الخروج | اخرج بعد عرض نص مخصص | شاشة الدخول تعود للنص الافتراضي ولا تحتفظ بنص العميل |
| 23 | تبديل سريع | بدّل اللغة/التطبيق سريعًا مع شبكة بطيئة | آخر اختيار فقط هو الذي يظهر ولا يستبدله رد قديم |
| 24 | منع التكرار | نفّذ إدخالين متزامنين للمفتاح/اللغة/التطبيق نفسه | يبقى سجل واحد فقط وترفض قاعدة البيانات التكرار |
| 25 | فشل الشبكة | اقطع الشبكة أثناء الحفظ | تظهر رسالة خطأ ولا تعرض الشاشة نجاحًا وهميًا |

## نقاط الـ API لفرق QA والتكامل

| العملية | الطلب | الصلاحية |
|---|---|---|
| حزمة اللغة الفعلية | `GET /api/v1/i18n/{locale}` | عامة، وتصبح خاصة بالتطبيق تلقائيًا عند وجود JWT |
| قائمة التطبيقات | `GET /api/v1/i18n/admin/apps` | `SUPER_ADMIN` |
| قائمة النصوص | `GET /api/v1/i18n/admin/translations?locale=ar-EG&appId=...` | `SUPER_ADMIN` |
| حفظ افتراضي/مخصص | `PUT /api/v1/i18n/admin/translations/{key}` | `SUPER_ADMIN` |
| العودة للافتراضي | `DELETE /api/v1/i18n/admin/translations/{key}?locale=...&appId=...` | `SUPER_ADMIN` |

جسم الحفظ:

```json
{
  "locale": "ar-EG",
  "appId": null,
  "textValue": "النص الجديد"
}
```

استخدم `appId: null` للنص الافتراضي، أو رقم التطبيق لإنشاء Override.
