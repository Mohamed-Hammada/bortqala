## Rule

Historical `[x]` checkboxes are not proof of implementation.

The corrected checklist uses:
- `[x] VERIFIED` only for verified complete behavior;
- `SOURCE PRESENT` for existing source without complete acceptance evidence;
- `PARTIAL` for known incomplete business/integration paths;
- `VERIFY` when more evidence is required.

Use relative Git paths only. Do not use local `file:///d:/...` links.
