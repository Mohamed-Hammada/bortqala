# Integration routes

## ZKTeco
- Classic/modern PULL direct-device communication
- ADMS / TA PUSH and AC PUSH device-initiated flows
- ZKBio Time / CVSecurity / CVAccess / WDMS / cloud-platform APIs
- Standalone SDK / zkemkeeper bridge
- plcommpro access-panel bridge
- ZKFinger scanner SDK boundary

## Hikvision
- ISAPI HTTP REST-style device integration for compatible network devices
- HCNetSDK/native device SDK integration boundary
- HikCentral/Open Platform integration boundary

## Dahua
- NetSDK native integration boundary
- DSS Professional OpenAPI integration boundary
- Event callback receiver

## Suprema
- BioStar 2 local/server API
- BioStar Device SDK native bridge
- G-SDK/gRPC integration boundary
- Legacy BioStar 1 is treated as a separate migration/legacy path

## Virdi / UnionBiometrics
- UBio Alpeta API
- UCS SDK native integration boundary
- UNIS legacy/platform migration boundary

## Anviz
- CrossChex Cloud API
- CrossChex webhook ingress
- Standard SDK/native integration boundary

## Honeywell
- Pro-Watch Web Services/API
- Honeywell HSDK integration boundary
- Panel generations are normally integrated through Pro-Watch rather than by reverse-engineering controller protocols.
