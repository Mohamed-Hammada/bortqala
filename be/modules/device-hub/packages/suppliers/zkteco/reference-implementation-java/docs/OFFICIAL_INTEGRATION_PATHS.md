# Official ZKTeco integration paths represented

This repo is designed around ZKTeco's published product/SDK split rather than assuming a single universal SDK:

- PUSH SDK / device-initiated integrations.
- Standalone/PULL SDK generations for terminals and controllers.
- ZKBio Time API for ERP/HR synchronization.
- ZKBio CVSecurity third-party API.
- ZKBio CVAccess / WDMS platform integration boundaries.
- ZKFinger SDKs for Windows, Linux and Android scanners.
- Visible-light / biometric module SDK integration boundary.

As of August 2026, ZKTeco's public site lists ZKBio Time 9.0.6, ZKBio CVSecurity 6.8.0 and ZKBio CVAccess 4.4.0 downloads. API manuals/SDK packages can have licensing or member-login conditions, so this repository does not redistribute them.
