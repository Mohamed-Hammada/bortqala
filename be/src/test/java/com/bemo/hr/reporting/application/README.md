# Reporting-period tests / اختبارات فترات التقارير

**EN:** Verifies that active monthly categories expose full-month periods, half-monthly categories expose 1–15 and 16–month-end periods, and only an exactly existing period is hidden.

**AR:** يتأكد من إظهار الشهر الكامل للفئات الشهرية، والفترتين 1–15 و16–نهاية الشهر للفئات نصف الشهرية، وإخفاء الفترة المطابقة الموجودة فقط.
