# Reporting capability / التقارير والمراجعة

**EN:** Will own report periods, calculated daily snapshots, exception decisions, approval, and Excel exports.

**AR:** مسؤولة عن فترات التقارير والنتائج اليومية المجمدة وقرارات الاستثناء والاعتماد وتصدير Excel.

**EN:** Daily biometric anomalies are persisted per report/date/category with configurable thresholds, affected payroll minutes, idempotent decisions, defer/reopen, audited reversal, and immutable before-decision snapshots.

**AR:** تُحفظ حالات شذوذ البصمة اليومية حسب التقرير والتاريخ والفئة، مع نسبة اكتشاف قابلة للضبط، ودقائق الأجر المتأثرة، وقرارات غير مكررة، وتأجيل وإعادة فتح وتراجع مسجل ولقطة للحالة السابقة.
