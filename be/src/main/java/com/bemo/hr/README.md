# HR Platform / منصة الموارد البشرية

**EN:** Spring Boot modular monolith. Capability packages own their business rules; cross-cutting code belongs in `shared` only when it has multiple real consumers.

**AR:** تطبيق Spring Boot بنمط modular monolith. كل حزمة وظيفية تملك قواعدها، ولا يوضع الكود المشترك داخل `shared` إلا عند وجود أكثر من مستهلك فعلي.
