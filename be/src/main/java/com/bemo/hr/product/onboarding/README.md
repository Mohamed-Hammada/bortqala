# Guided onboarding and data quality / التجهيز الموجّه وجودة البيانات

**EN:** The assessment consumes the installed industry pack's own ordered steps; it does not create a second checklist. Real tenant-scoped repository evidence drives five quality checks and automatic completion. A workforce import counts only after `IMPORTED`. Optional steps remain `READY` until real evidence exists or a user explicitly records `SKIPPED`. Assessments lock the pack, use a pack-scoped operation ID, persist immutable scores/issues, and audit the actor.

Go-live is `READY` only when every required step is completed and data quality is at least 80. Every missing check returns a localized issue and an actionable application route.

**AR:** يستهلك التقييم الخطوات المرتبة نفسها في حزمة النشاط المثبتة ولا ينشئ قائمة موازية. تقود أدلة المستأجر الفعلية خمسة فحوص جودة والإكمال التلقائي، ولا يُحتسب استيراد العمالة إلا بعد حالة `IMPORTED`. تظل الخطوات الاختيارية `READY` حتى يوجد دليل حقيقي أو يسجل المستخدم `SKIPPED` صراحةً. يقفل التقييم الحزمة ويستخدم معرف عملية خاصًا بها ويحفظ الدرجات والعوائق كدليل غير قابل للتغيير مع تدقيق المنفذ.

لا تصبح الجاهزية `READY` إلا بعد اكتمال كل الخطوات الإلزامية ووصول جودة البيانات إلى 80 على الأقل. يعيد كل نقص رسالة مترجمة ومسارًا مباشرًا للمعالجة.
