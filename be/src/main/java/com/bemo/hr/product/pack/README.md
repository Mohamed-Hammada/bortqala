# Industry packs / حزم الأنشطة

**EN:** Industry packs configure the shared platform without branches. Install resolves required entitlements, records version/default evidence and creates ordered onboarding. Commands are tenant-scoped, audited and retry-safe. Upgrade changes only non-customized defaults; customer JSON is preserved.

**AR:** تضبط حزم الأنشطة المنصة المشتركة دون فروع كود. يحل التثبيت الاستحقاقات المطلوبة ويسجل الإصدار والإعدادات وينشئ تجهيزاً مرتباً. الأوامر معزولة ومدققة وآمنة عند الإعادة، ولا تستبدل الترقية إعدادات العميل المخصصة.
