# Executive Analytics & Reporting / التحليلات والتقارير التنفيذية

**EN:** Provides a unified server-side semantic KPI registry, multi-module business intelligence overview, period-over-period trend analysis, and historical executive snapshot recording. Aggregates live data across General Ledger, Sales, POS, Inventory, Projects, Workforce, and ETA Tax compliance without relying on browser-paged calculations.

**AR:** يوفر سجلاً دلالياً موحداً لمؤشرات الأداء الرئيسية على مستوى الخادم، ولوحة معلومات تنفيذية شاملة تجمع الأداء المالي والتجاري والمخزني والمشاريع والقوى العاملة والامتثال الضريبي. يتيح مقارنة الاتجاهات عبر الفترات وحفظ لقطات تنفيذية دورية دون الاعتماد على حسابات المتصفح الجزئية.
