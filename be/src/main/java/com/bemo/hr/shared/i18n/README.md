# Database i18n / الترجمة من قاعدة البيانات

**EN:** Public read-only translation bundles for `ar-EG` and `en-US`. Translation rows are platform UI text shared by SaaS applications and managed through versioned Liquibase data so releases remain reproducible.

**AR:** حزم ترجمة للواجهة بالعربية والإنجليزية تُقرأ دون تسجيل دخول. الصفوف نصوص منصة مشتركة بين تطبيقات SaaS وتدار ببيانات Liquibase ذات إصدارات لضمان إمكانية إعادة بناء كل إصدار.
