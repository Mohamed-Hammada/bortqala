# Shared API / واجهات مشتركة

**EN:** RFC 9457 problem-detail mapping and the global epoch-millisecond contract for `Instant` and `LocalDate`. Local dates use the configured company zone; `LocalTime` remains `HH:mm`.

**AR:** تحويل الأخطاء إلى RFC 9457 وتطبيق عقد مركزي يرسل `Instant` و`LocalDate` كـ epoch milliseconds، مع استخدام المنطقة الزمنية للشركة للتاريخ المحلي وبقاء `LocalTime` بصيغة `HH:mm`.
