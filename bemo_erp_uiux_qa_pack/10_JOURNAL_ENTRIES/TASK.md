# TASK 10 — Journal Entries

Priority: P1
Status: ☑ Verified

## Required
1. Primary line row contains Account, Debit, Credit and actions.
2. Analytical dimensions are in an expandable sub-row.
3. Expanded state is keyboard accessible.
4. Debit/credit validation is immediate and understandable.
5. Journal balance is visible and updates correctly.
6. Unbalanced journals cannot be posted.
7. Account lookup remains usable with many accounts.
8. Memo does not force the primary row to become excessively wide.
9. Cost Center/Project/WBS/Cost Code/Department fields are preserved when collapsing.
10. Mobile/tablet layout remains usable.
11. Server validation errors map to the correct line.
12. Adding/removing a line does not unexpectedly change focus.

## Acceptance
Test 1 line, 2 lines, 100+ lines, invalid amounts, unbalanced journal and server rejection.
