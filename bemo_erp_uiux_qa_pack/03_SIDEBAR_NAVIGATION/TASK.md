# TASK 03 — Sidebar Navigation

Priority: P1
Status: ☑ Verified

## Objective
Provide predictable navigation and independent favorite actions.

## Required behavior
1. Navigation link and favorite star are separate interactive elements.
2. Clicking the star never navigates.
3. Clicking the link never toggles favorite.
4. Tab reaches link and star independently.
5. Enter on link navigates.
6. Space/Enter on star toggles favorite according to button semantics.
7. Active route styling is correct after navigation.
8. Favorite and recent lists update without duplicate entries.
9. Removing a favorite does not remove the route from recents.
10. Collapsed sidebar still exposes an accessible label/tooltip.
11. Tooltips do not obscure the star action.
12. RTL layout keeps link and star order sensible.
13. Mobile sidebar has a clear close behavior.

## Visual QA
Check 1920, 1366, 1024, 768 and 390px widths.
