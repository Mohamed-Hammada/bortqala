# TASK 04 — Sidebar Information Architecture

Priority: P2
Status: ☑ Verified

## Objective
Reduce navigation overload without hiding important modules.

## Required
1. Core operational modules are expanded by default.
2. Secondary/vertical modules are collapsed by default.
3. Collapse state is persistent where intended.
4. Favorites and Recently Used remain immediately accessible.
5. No module appears in two unrelated groups.
6. Labels/descriptions are understandable in both Arabic and English.
7. Long labels do not break layout.
8. Empty workspace groups are hidden.
9. Permission-hidden items never leave empty group shells.
10. The final IA must be documented in the navigation configuration.

## Do not accept
A visual collapse that merely hides content while keyboard focus remains inside hidden controls.
