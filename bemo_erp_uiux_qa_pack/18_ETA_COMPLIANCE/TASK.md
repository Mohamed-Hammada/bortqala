# TASK 18 — ETA / Tax

Priority: P1
Status: ☑ Verified

## Required
1. Submission status is explicit.
2. Accepted/rejected/pending states are distinct.
3. Tax identifiers are formatted/validated consistently.
4. API rejection details are shown in understandable form.
5. Retry does not duplicate a successful submission.
6. Documents show submission reference where available.
7. Compliance failures cannot be mistaken for UI/network success.
8. Sensitive tax data is not exposed in unnecessary logs/UI.
