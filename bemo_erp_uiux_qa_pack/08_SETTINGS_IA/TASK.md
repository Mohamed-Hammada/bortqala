# TASK 08 — Settings Information Architecture

Priority: P1
Status: ☑ Verified

## Required structure
Personal:
- Appearance
- Language
- Navigation
- Notifications
- Shortcuts

Business/Company:
- Business Vertical
- Business Policies
- Company configuration

Security/Session:
- Session timeout
- Authentication/security controls

Integrations:
- External integrations

## Acceptance
1. Business configuration is not rendered under Session.
2. Each tab contains only semantically related settings.
3. Deep links/opening a tab preserve the selected tab.
4. Tab names are localized.
5. Empty/unavailable tabs are hidden or clearly disabled with explanation.
6. Browser back/forward works predictably.
