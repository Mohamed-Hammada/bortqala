# TASK 27 — i18n QA

Priority: P1/P2
Status: ☑ Verified

## Required
1. Every visible UI string has a translation key.
2. Arabic and English keys are paired.
3. No raw fallback text remains unintentionally.
4. Arabic does not overflow controls.
5. Dates/numbers/currency use locale rules.
6. Direction changes correctly for RTL.
7. Shortcut names and hints are localized.
8. Validation and error messages are localized.
9. Tooltips are localized.
10. Long translations are tested at mobile width.
