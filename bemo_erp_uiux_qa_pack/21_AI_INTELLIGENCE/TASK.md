# TASK 21 — AI Intelligence

Priority: P2
Status: ☑ Verified

## Required
1. AI-generated insight is clearly labeled as generated insight.
2. Loading state explains what is being calculated.
3. Failure state provides retry.
4. Stale insight/data timestamp is visible.
5. Actions suggested by AI are not executed silently.
6. Sensitive data is not displayed unnecessarily.
7. Long AI output remains readable and does not break layout.
8. Keyboard navigation works through insight cards/actions.
