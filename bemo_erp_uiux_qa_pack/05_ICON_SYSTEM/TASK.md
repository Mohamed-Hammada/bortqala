# TASK 05 — Icon System

Priority: P2
Status: ☑ Verified

## Scope
Application shell, sidebar, header, notifications, favorites, dashboard navigation.

## Required
1. Shell chrome uses the standard SVG/icon component.
2. Emoji are not used as primary navigation/control icons.
3. Icon size and baseline are consistent.
4. Icons have accessible labels where they convey meaning.
5. Decorative icons are hidden from assistive technology.
6. Arabic RTL does not mirror icons incorrectly.
7. Newly added icons follow the same naming convention.
8. Missing icon names fail visibly in development rather than silently rendering inconsistent glyphs.
