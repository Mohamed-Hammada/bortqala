# TASK 12 — Shared Form UX

Priority: P1/P2
Status: ☑ Verified

## Required
1. Required fields are identifiable.
2. Errors are attached to fields.
3. First invalid field can receive focus.
4. Server validation errors are distinguishable from network errors.
5. Saving state disables destructive duplicate submissions.
6. Save failure retains user-entered values.
7. Cancel behavior is explicit.
8. Dirty state is tracked for complex forms.
9. Date/time/currency/number inputs use localized display but stable API values.
10. Error messages contain actionable text, not only generic failure wording.
