# License persistence / تخزين التراخيص

## English

Repositories store only SHA-256 license-key hashes and public device identity. The server signing private key remains in environment-backed secret storage.

## العربية

تحفظ المستودعات بصمة SHA-256 لمفتاح الترخيص وهوية الجهاز العامة فقط. يبقى مفتاح توقيع الخادم الخاص في مخزن أسرار يوفره التشغيل.
