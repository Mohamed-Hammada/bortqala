# License domain / نطاق الترخيص

## English

`LicenseKey` is the commercial entitlement and `LicenseActivation` is one bound installation. Perpetual licenses have no expiry; term and fixed-date licenses carry an activation expiry. Deactivation preserves the installation record so the same device can reactivate it safely and audibly.

## العربية

يمثل `LicenseKey` الاستحقاق التجاري، ويمثل `LicenseActivation` تثبيتًا مرتبطًا بجهاز. الترخيص الدائم بلا انتهاء، بينما يحمل الترخيص المحدد بسنوات أو بتاريخ موعد انتهاء. يحتفظ إلغاء التفعيل بسجل التثبيت ليمكن إعادة تفعيل الجهاز نفسه بأمان ومع بقاء الأثر.
