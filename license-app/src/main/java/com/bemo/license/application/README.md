# License application / منطق الترخيص

## English

This package enforces license duration, activation limits, device proof, online validation, deactivation, reactivation of the same installation, and server certificate signing. Seat allocation locks the licence row before counting active installations. Never expose the signing private key to a client or log raw license keys.

## العربية

تطبق هذه الحزمة مدة الترخيص وحد التفعيلات وإثبات الجهاز والتحقق عبر الإنترنت وإلغاء التفعيل وإعادة تفعيل التثبيت نفسه وتوقيع شهادة الخادم. يقفل تخصيص المقاعد صف الترخيص قبل عد التفعيلات النشطة. يمنع وضع المفتاح الخاص داخل العميل أو تسجيل مفاتيح الترخيص الخام في السجلات.
