# License application / منطق الترخيص

## English

This package enforces license duration, activation limits, device proof, online validation, deactivation, and server certificate signing. Never expose the signing private key to a client or log raw license keys.

## العربية

تطبق هذه الحزمة مدة الترخيص وحد التفعيلات وإثبات الجهاز والتحقق عبر الإنترنت وإلغاء التفعيل وتوقيع شهادة الخادم. يمنع وضع المفتاح الخاص داخل العميل أو تسجيل مفاتيح الترخيص الخام في السجلات.
