# Shell / قالب التطبيق

**EN:** Responsive RTL navigation filtered by the authenticated user's multiple roles.

**AR:** تنقل RTL متجاوب يظهر حسب الأدوار المتعددة للمستخدم الحالي.

**EN:** The shell displays a keyboard-accessible backend connection indicator with application version details and a manual retry action. It uses the database-backed status contract rather than relying only on `navigator.onLine`.

**AR:** يعرض القالب مؤشراً متاحاً بلوحة المفاتيح لاتصال الخادم، مع إصدار التطبيق وإعادة الفحص يدوياً، ويعتمد على فحص فعلي من الخادم وليس على حالة المتصفح فقط.

## 2026-08-10 navigation-control polish

**EN:** Expand-all/collapse-all navigation controls now use direction-neutral double-chevron icons. Their action group follows inline start, so it appears on the right in RTL and on the left in LTR. The sidebar panel-collapse icon is mirrored for LTR.

**AR:** تستخدم أزرار فتح/غلق مجموعات القائمة الآن أسهماً مزدوجة واضحة لا تعتمد على اتجاه اللغة، وتظهر مجموعة الأزرار في بداية الاتجاه الصحيح: يميناً في RTL ويساراً في LTR.
