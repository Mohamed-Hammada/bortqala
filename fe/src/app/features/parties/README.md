# Business parties / جهات التعامل

**EN:** Tenant business directory for suppliers, processing customers, export customers, farms, and user-entered future types. It supports search, five-row default pagination, Excel export, optimistic updates, and an Escape-close drawer.

**AR:** دليل جهات التعامل للموردين وعملاء التشغيل وعملاء التصدير والمزارع والأنواع الجديدة التي يكتبها المستخدم. يدعم البحث، وترقيم الصفحات من خمسة صفوف افتراضيًا، وتصدير Excel، والتعديل الآمن، وإغلاق اللوحة بمفتاح Escape.

## Supplier onboarding / تأهيل الموردين

**EN:** Creating a supplier starts an onboarding request instead of silently activating it. Supplier 360 shows lifecycle state, compliance checks, uploaded documents with secure downloads, bank verification, duplicate warnings, and the allowed transition actions. All visible copy is database-backed in Arabic and English.

**AR:** يبدأ إنشاء المورد طلب تأهيل بدل تفعيله ضمنيًا. يعرض ملف المورد الشامل حالة الدورة، وفحوص الامتثال، والمستندات المرفوعة مع تنزيل آمن، والتحقق البنكي، وتحذيرات التكرار، وإجراءات الانتقال المسموحة. جميع النصوص الظاهرة مدعومة من قاعدة البيانات بالعربية والإنجليزية.
