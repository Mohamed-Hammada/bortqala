# Employees / الموظفون

**EN:** Employee directory, category assignment, fixed/daily employment, active dates, and optional stable biometric device mapping. The create/edit drawer occupies the viewport height and keeps its final actions reachable while the form scrolls.

تملأ نافذة إضافة/تعديل الموظف ارتفاع الشاشة، وتبقى أزرار الحفظ والإلغاء قابلة للوصول أثناء تمرير الحقول حتى النهاية.

**AR:** دليل الموظفين وربط الفئة والتعيين الثابت/اليومية وفترة النشاط ورقم جهاز البصمة الاختياري.
