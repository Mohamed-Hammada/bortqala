# Banks and reconciliation / البنوك والتسوية

**EN:** The page combines bank-account setup, statement import, reconciliation workbench, and cash position. CSV imports upload the real file, exact suggestions come from the backend, users may adjust partial allocations and bank fees, and active matches can be reversed with a required reason. The frontend formats results but never reproduces accounting or matching rules.

**AR:** تجمع الصفحة إعداد الحسابات البنكية، واستيراد الكشوف، وشاشة التسوية، والموقف النقدي. يرفع الاستيراد ملف CSV الفعلي، وتأتي اقتراحات المطابقة من الخلفية، ويمكن للمستخدم تعديل التخصيص الجزئي والرسوم البنكية، كما يمكن عكس المطابقة النشطة بسبب إلزامي. تنسق الواجهة النتائج ولا تعيد تنفيذ قواعد المحاسبة أو المطابقة.
