# Tax & Currency / الضرائب والعملات

**EN:** The Currencies tab shows the configured ERP rate beside the Frankfurter online hint, provider date, and difference percentage. Admin/Super Admin users can enable or disable the integration and configure its interval (default 4 hours); Finance Managers may manually refresh. Online rates never overwrite configured rates.

**AR:** يعرض تبويب العملات سعر النظام المعتمد بجانب السعر المرجعي من Frankfurter وتاريخ المصدر ونسبة الفرق. يستطيع المسؤولون تفعيل الربط أو إيقافه وتحديد فترة التحديث (الافتراضي 4 ساعات)، ويمكن لمدير المالية تشغيل تحديث يدوي. لا يتم استبدال السعر المعتمد تلقائياً.
