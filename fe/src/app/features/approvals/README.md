# Approval workspace / مساحة الاعتمادات

**EN:** The pending-approval page is exception-first: summary cards show total, overdue, and delegated work; filters isolate overdue or delegated tasks; each row shows `received / required` signatures and aging. History identifies decisions made under delegation and the immutable workflow version.

**AR:** تعرض صفحة الاعتمادات الاستثناءات أولاً: بطاقات لإجمالي المهام والمتأخر والمفوّض، ومرشحات لعزل المهام المتأخرة أو المفوضة، ويظهر كل صف عدد التوقيعات `المستلم / المطلوب` والعمر. يوضح السجل القرارات المنفذة بالتفويض وإصدار المسار الثابت.

**EN:** Users create and deactivate date-bounded delegations in the same workspace. Workflow administrators configure the minimum `ANY_N` signatures and SLA hours per step.

**AR:** ينشئ المستخدم التفويض المحدد بتاريخ ويوقفه من المساحة نفسها، ويحدد مسؤول المسارات الحد الأدنى لتوقيعات `ANY_N` وساعات مستوى الخدمة لكل خطوة.
