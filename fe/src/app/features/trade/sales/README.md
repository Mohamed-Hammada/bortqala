# Sales workspace / مساحة عمل المبيعات

**EN:** The page combines sales orders with an AR workbench for invoices, issue actions, receipts and optional allocation, backend-provided aging buckets, overdue collection tasks, and customer credit controls. Every refresh reloads the server-calculated balances.

**AR:** تجمع الصفحة أوامر البيع مع منضدة الذمم المدينة للفواتير والإصدار والتحصيل والتخصيص الاختياري وأعمار الديون المحسوبة في الخادم ومهام المتأخرات وضوابط ائتمان العميل. ويعيد كل تحديث تحميل الأرصدة المحسوبة من الخادم.
