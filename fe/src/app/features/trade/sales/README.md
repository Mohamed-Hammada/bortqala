# Sales workspace / مساحة عمل المبيعات

**EN:** The page combines sales orders with an AR workbench for invoices, issue actions, receipts and optional allocation, backend-provided aging buckets, overdue collection tasks, and customer credit controls. Every refresh reloads the server-calculated balances.

**EN:** The order dialog submits typed item lines plus warehouse and currency. Confirm reserves stock and freezes backend pricing; Deliver and invoice runs the connected backend lifecycle. Inspect flow displays delivery, invoice, movement/COGS, return, and credit-note references, while the return form submits a quantity against a specific delivered line. The UI never recalculates ATP, COGS, AR, or credits.

**AR:** يرسل مربع أمر البيع بنود أصناف محددة النوع مع المخزن والعملة. يحجز التأكيد المخزون ويجمد التسعير في الخادم، وينفذ إجراء التسليم والفوترة المسار الخلفي المترابط. يعرض فحص المسار مراجع التسليم والفاتورة والحركة والتكلفة والمرتجع وإشعار الدائن، ويرسل نموذج المرتجع كمية مرتبطة ببند تسليم محدد. لا تعيد الواجهة حساب المخزون المتاح أو التكلفة أو الذمم أو الرصيد الدائن.

**AR:** تجمع الصفحة أوامر البيع مع منضدة الذمم المدينة للفواتير والإصدار والتحصيل والتخصيص الاختياري وأعمار الديون المحسوبة في الخادم ومهام المتأخرات وضوابط ائتمان العميل. ويعيد كل تحديث تحميل الأرصدة المحسوبة من الخادم.
