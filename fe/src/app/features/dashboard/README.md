# Dashboard / لوحة المتابعة

**EN:** Month-aware operational summary of report state, unresolved work, attendance, lateness, overtime, unmatched identities, categories, and imports.

## Custom dashboards / لوحات مخصصة

**EN:** The dashboard supports server-backed widget visibility and ordering, an accessible motion toggle, and richer attendance, payroll, and department charts. The editor is shown only when the effective user/admin policy permits customization.

**EN:** Customization and motion now appear in a dedicated toolbar directly below the dashboard header, with styled keyboard-accessible tooltips so the controls remain discoverable.

**AR:** تدعم لوحة المتابعة إظهار العناصر وإخفاءها وترتيبها مع حفظها على الخادم، وخياراً مستقلاً للحركة، ورسوم حضور ورواتب وإدارات أكثر ثراءً. ولا تظهر أداة التخصيص إلا عندما تسمح صلاحية المستخدم وسياسة المدير بذلك.

**AR:** يظهر التخصيص والحركة الآن في شريط مستقل أسفل عنوان اللوحة مباشرة، مع تلميحات مرئية ومنسقة تعمل أيضاً بتركيز لوحة المفاتيح لتسهيل الوصول إلى الأدوات.

**AR:** ملخص شهري لحالة التقرير والاستثناءات والحضور والتأخير والإضافي والهويات غير المربوطة والفئات والاستيرادات.
# Shared filters and drill-down / الفلاتر والانتقال للتفاصيل

**EN:** Dashboard period and organizational filters are persisted in URL query parameters. Workforce KPI cards and chart bars navigate to their related detail pages with the active filter context.

**AR:** تُحفظ فلاتر الفترة والتنظيم في رابط لوحة المتابعة، وتنتقل بطاقات ورسوم لوحة القوى العاملة إلى صفحات التفاصيل مع سياق الفلاتر الفعال.
