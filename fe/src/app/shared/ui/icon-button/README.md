# Icon button / زر الأيقونة

**AR:** استخدم `app-icon-button` لكل إجراء يعتمد على أيقونة فقط. المكون يفرض اسماً قابلاً للوصول، وتلميحاً موحداً يدعم الوصف واسم السجل واختصار لوحة المفاتيح، ويستفيد من مهلة 350ms ودعم التركيز وEscape وRTL في `AppTooltipDirective`.

**EN:** Use `app-icon-button` for every icon-only action. It enforces an accessible name and a consistent tooltip that can include the action description, record name, and keyboard shortcut. Tooltip delay, keyboard focus, Escape dismissal, and RTL are provided by `AppTooltipDirective`.
