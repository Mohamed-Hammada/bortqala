# Table pagination / ترقيم صفحات الجداول

**EN:** Reusable client-side paginator for the current MVP tables. It defaults to 5 rows and offers 5, 10, 50, or 100 rows while preserving the parent feature's filters. Replace the parent data source with server pagination when installations become large.

**AR:** مكوّن موحد لترقيم صفحات جداول المرحلة الحالية. يبدأ بخمسة صفوف ويتيح 5 أو 10 أو 50 أو 100 صف مع استمرار فلاتر الصفحة. عند كبر حجم البيانات يجب نقل جلب الصفحات إلى الخادم مع الاحتفاظ بنفس المكوّن.
