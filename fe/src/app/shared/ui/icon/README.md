# Icons / الأيقونات

**EN:** Small accessible inline SVG icon component for application navigation and actions. It adds no external icon dependency and decorative SVGs remain hidden from assistive technology while their controls provide labels.

**AR:** مكون SVG صغير لأيقونات التنقل والإجراءات دون مكتبة خارجية. الأيقونة الزخرفية مخفية عن قارئ الشاشة بينما يحمل الزر أو الرابط اسم وصول واضحًا.
