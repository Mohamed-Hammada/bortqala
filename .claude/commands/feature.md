# Feature Implementation Command

Implement the requested feature with minimal context.

1. Map request to module.
2. Inspect existing patterns and nearest analogous feature.
3. Identify backend, DB, frontend, permissions, i18n, and tests affected.
4. Implement incrementally.
5. Add regression/feature tests.
6. Run focused checks.
7. Run broader checks if the change crosses module boundaries.
8. Summarize changed contracts and verification status.
