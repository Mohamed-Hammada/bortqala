# QA Command

Execute a focused QA workflow.

1. Identify the requested feature and affected module.
2. Read only the necessary module docs/source/tests.
3. Reproduce the issue or validate the requested behavior.
4. Use Playwright/browser tooling for UI flows when applicable.
5. Record every issue immediately in the requested QA report.
6. Retest failures after fixes.
7. Finish with:
   - tested scope
   - issues found
   - fixed vs open
   - evidence
   - commands/tests run
   - blockers
