# Bug Investigation Command

Investigate a bug without broad repository loading.

1. Restate the symptom in one sentence.
2. Locate the narrowest affected feature/module.
3. Trace the smallest relevant path from entry point to side effect.
4. Check existing tests and recent changes.
5. Reproduce with a focused test or runtime flow.
6. Identify root cause before editing.
7. Implement the minimal safe fix.
8. Add/adjust regression coverage.
9. Run focused verification and report any remaining uncertainty.
