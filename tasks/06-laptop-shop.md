# TASK 06 — Laptop / Computer Shop Domain
## Product data
Brand, Model, CPU, CPU Generation, RAM, Storage, GPU, Screen, Resolution, Refresh Rate, OS, Keyboard Layout, Warranty, Serial Number, Condition, Color.
## Lifecycle
Purchase → Serial Registration → Stock → Sale → Customer → Warranty → Return/Exchange → Repair.
## Acceptance Criteria
- [ ] Serialized inventory supported.
- [ ] Serial uniqueness enforced.
- [ ] Sale records exact serial.
- [ ] Customer-device relationship exists.
- [ ] Warranty lifecycle works.
- [ ] RMA/repair references device.
- [ ] Used/refurbished condition supported.
- [ ] POS integration works.
- [ ] Inventory/accounting remain consistent.
