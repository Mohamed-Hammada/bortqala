# TASK 04 — Menu + API Security
## Goal
Menu hiding must never be the authorization mechanism.
## Required layers
1. Frontend visibility
2. Backend authorization
3. Data-level tenant/domain/scope enforcement
## Acceptance Criteria
- [ ] Unauthorized menu hidden.
- [ ] Direct route rejected.
- [ ] Direct API call rejected.
- [ ] Cross-tenant object access rejected.
- [ ] Cross-domain object access rejected.
- [ ] Update/delete endpoints enforce the same policy.
