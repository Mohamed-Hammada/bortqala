# TASK 12 — Core ERP End-to-End
## Workflows
### Procure to Pay
Request → Approval → PO → Receipt → Inventory → Supplier Invoice → 3-Way Match → AP → Payment → GL.
### Order to Cash
Quotation → Sales Order → Credit Check → Reservation → Delivery → COGS → Invoice → AR → Receipt → Cash/Bank → GL.
### Payroll
Inputs → Freeze → Snapshot → Calculate → Review → Approve → Post → Pay.
### Manufacturing
BOM → Production Order → Material/Labor/Overhead → Scrap → Finished Goods → Cost → Inventory → GL.
### Projects
Project → WBS/BOQ → Tender → Contract → Budget → Procurement → Materials/Labor → Progress → IPC → Revenue → Collection → Profitability.
## Acceptance Criteria
- [ ] Happy path works.
- [ ] Partial transactions work.
- [ ] Rejection/cancellation works.
- [ ] Returns/credit notes work.
- [ ] Duplicate/concurrent requests are safe.
- [ ] Operational and accounting results reconcile.
