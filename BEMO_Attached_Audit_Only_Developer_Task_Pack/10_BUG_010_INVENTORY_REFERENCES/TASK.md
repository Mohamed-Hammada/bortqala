# BUG-010 — Inventory movement lacks distinct document references

Priority: **MEDIUM**

Supply receipt has one reference but does not clearly separate purchase order, goods receipt, supplier invoice and external reference.

Acceptance:
- [x] Distinct references exist where applicable.
- [x] Requiredness depends on movement type.
- [x] References appear in relevant list/detail views.
- [x] Attachment linkage is clear.

## Completion rule
The developer must not mark the index item complete until the acceptance checks above have been verified.
